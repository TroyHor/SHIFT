# SHIFT · 烟斗侦探 — 美术风格

**风格名**：白昼里的一块夜（犯罪现场模型）
**版本**：1.0（2026-11-06）

## 一句话

每一关是一座**犯罪现场模型**：剖开屋顶的小房子，木头小人站在圆底座上。现在是案发后的**清晨**，阴天的白光照着空荡荡的现场；侦探吐一口烟，烟圈滚开的地方变回**案发当晚的夜**：深蓝的月光，台灯、蜡烛和烟斗的暖光。

关键词：模型、清晨与深夜、烟圈、手工感、安静、可读

## 为什么是这个风格

| 游戏里的事实 | 风格怎么回应 |
|---|---|
| 目前每一关的"现在"都是早上（8:00、7:00、6:00），"过去"都是夜里（22:50、21:00、23:10） | 两个时代用**光**区分，不用调色：现在白天，烟里黑夜。一眼就看出哪几格是过去 |
| 俯视、格子、回合制 | 模型和棋子：俯视看模型是最自然的角度，侦探走一步就像挪一下棋子 |
| 主角是抽烟斗的侦探 | 烟雾窗口就是他吐出的**烟圈**：一圈翻滚的烟管滚出去、再卷回来 |
| 真实历史：1940 年代美国警方用来训练侦探的"犯罪现场微缩模型"（Nutshell Studies） | 题材本身就是侦探的工具，西方、年代感对，和黑色电影同一时代 |

## 白天还是黑夜：按关卡的时间点自动决定

每个时代是白天还是黑夜，由关卡里写的时间（`present_label`、`past_label` 里的 `22:50` 这类时间）决定：19:00 以后、6:00 以前算黑夜。

| 现在 | 案发 | 画面 |
|---|---|---|
| 白天 | 黑夜 | 白天的模型里裂开一块黑夜（目前所有关卡） |
| 黑夜 | 白天 | 黑夜里亮着台灯，烟里是一块白天 |
| 白天 | 白天 | 烟里换成黄昏的暖光 |
| 黑夜 | 黑夜 | 烟里换成黄昏的暖光 |

台灯这类"只在夜里亮"的东西跟着各自时代的光走。时间没写就当作现在白天、过去黑夜。

## 1. 颜色

| 角色 | 颜色 | 用在哪 |
|---|---|---|
| 清晨天光 | `#F4F6FA` 日光、`#A8BCE0` 补光 | 现在：整张地图 |
| 夜里月光 | 日光 × `(0.045, 0.065, 0.15)` | 黑夜：没有灯照到的地方是深蓝 |
| 灯光 | `#FFB360` 左右 | 烟里：台灯、蜡烛、烟斗火、烟圈中心 |
| 烟 | `#F7F2E6` 亮面、`#7A808F` 暗面 | 烟圈；朝里的一面被灯照成暖色 |
| 墙顶剖面 | 书房 `#807868`、旅馆 `#8A7A68`、列车 `#807D7A` | 墙顶，外露的边描深色线 |
| 模型底座 | 胡桃木 `#3A2416` + 黄铜线 `#B08A50` | 地图外的一圈 |
| 界面金色 | `#E0B46A` | 可以拿的东西、指着的东西、侦探底座 |

规则：
- 物件只定义一次"真实颜色"，不按时代改材质。时代由着色器按位置换光（`scripts/board3d.gd` 的 `SHADE_COMMON`）。
- 现在的颜色淡 20%（案发后），烟里保留原色。
- 烟管在地上压出一圈影子（里外各 0.45 格），窗口的边一眼看得出。
- 不要用：整屏的冷蓝或暖褐滤镜、胶片颗粒和划痕、墨线描边、卡通分层光。

## 2. 线条

- 不描边。轮廓靠光影和圆角边上的高光。
- 唯一的"线"是墙顶剖面外露的那一圈深色边，像切开的卡纸墙。

## 3. 形状

- 家具：圆角方块（`_box()` 自动加 0.8–4.5 厘米的圆角），像手工做的木模型。薄板、地面、墙保持直角。
- 人物：上漆的木头小人。锥形身体、两只手臂、球形头，站在黑色圆底座上；侦探的底座镶金边。
- 帽子和一两件配饰决定身份（礼帽、厨师帽、白围裙、制服帽），要在 30 像素大小下也认得出。

## 4. 构图与镜头

- 固定透视镜头，俯角 58°，整张地图放在画面中间，下面露出一截模型底座。
- 主次：烟圈 > 人 > 可以互动的东西 > 家具 > 墙和地面。

## 5. 光

| | 白天 | 黑夜 | 黄昏（两个时代同为白天或黑夜时的烟里） |
|---|---|---|---|
| 主光 | 左上方高窗的白光，软阴影 | 同一方向的月光，只剩 1/20，偏蓝 | 一半亮度，偏暖 |
| 环境光 | 明亮的天光 | 几乎没有 | 一半 |
| 灯 | 不亮（台灯是灭的） | 台灯、点着的蜡烛、侦探的烟斗、烟圈中心都亮 | 微亮 |

- 只在夜里亮的灯用 `_lamp_m()`（灯泡）和 `_lamp_light()`（光源，只加在过去那一份物件上）。
- 环境光在着色器里自己算（兼容渲染器不认材质的 AO）。

## 6. 质感

- 地面按种类画花纹：书房拼花（相邻格木条方向交错）、旅馆长木板、列车地毯菱格、花园草地、雪地、站台水泥砖。冷地面结霜。
- 靠墙的地面压暗一圈（假的环境光遮蔽）。
- 墙的侧面：室内是墙纸 / 木板 / 车厢护墙板，朝室外的一面是砖墙 / 原木 / 车厢绿漆铆钉。
- 上漆的表面有小而亮的高光，金属更亮。

## 7. 动画

| 动画 | 做法 |
|---|---|
| 烟圈卷开 | Shift 后 0.75 秒：烟管从侦探脚下的一个小团，滚到 3x3 的边上。管子边滚边转（推出去多少就转多少），烟管经过一格时，这一格换成过去 |
| 烟圈卷回 | 走出烟雾或浓度用完，0.6 秒：烟管往中心滚回去，经过的格子换回现在，最后缩成一小团消失。不会散开 |
| 浓度 | 烟越淡，烟管越细；上沿的小圆点在烟圈张开后淡入 |
| 再吐一口 | 旧烟圈卷回、新烟圈同时卷开（最多两个） |
| 侦探 | 走一步像棋子一样跳一下；有烟丝时烟斗冒烟、火星闪 |
| 其他人 | 轻微呼吸；烟旁边的人踮脚看，看见过去的自己会发抖 |

## 8. 技术

- Godot 4.7 兼容渲染器（网页版也用它）。不用贴图，所有花纹在着色器里算。
- 烟雾窗口的位置通过全局着色器参数 `smoke_a`、`smoke_b`（中心 x、z、当前半宽）和 `smoke_all`（编辑器"过去"视图）传给所有表面；`era_night`（现在、过去各自 0 = 白天、1 = 黑夜）由 `Board3D.era_light()` 按时间点算出。都定义在 `project.godot` 的 `[shader_globals]`。
- 截图时可以强行指定光，看四种组合：`tools/shot.gd` 的第 5 个参数 `dn`、`nd`、`dd`、`nn`。
- 新物件：在 `_thing()` 里加一个分支，用 `_m(颜色, 粗糙度, 金属度)` 和 `_part()` 搭，自动得到两个时代的光。
- 截图：`tools/shot.gd`（见文件开头的用法）。

## 9. 要做 / 不要做

| 要做 | 不要做 |
|---|---|
| 用光区分时代 | 用整屏滤镜区分时代 |
| 夜里留下暖色灯光的小块，让人看得清 | 夜里一片漆黑，看不清线索 |
| 烟只卷开、卷回 | 烟消散、飘走、淡出 |
| 东西做得像手工模型：圆角、上漆 | 写实贴图、像素风、描边卡通 |
| 关键物件在 30 像素下认得出 | 靠很小的细节区分两个东西 |
