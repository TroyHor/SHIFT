# SHIFT · 烟斗侦探 — 设计文档

> GitHub Game Off 2026 参赛作品，主题 **SHIFT**。
> 截止：2026-12-01 21:37 UTC（北京时间 12 月 2 日 05:37）。源码必须放在公开仓库。
> 评分项：总体、玩法、画面、音效、创新、主题契合。

## 一句话

一位侦探能用烟斗吐出的烟穿越时间：**按下 Shift，身边 3x3 的格子变回案发当晚**。他站在两个时代的交界处，同时和过去、现在互动，以此破案。

## 主题契合

- **按下 Shift 键**：唯一的核心操作就是 Shift。
- **时间的位移**：烟雾里是过去，烟雾外是现在。
- **视角的切换**：同一个房间、同一个人，在两个时间点说的话、摆的位置都不一样。

## 核心规则（已确认）

| 规则 | 内容 |
|---|---|
| 开窗 | 按 Shift 花 1 撮烟丝吐一口烟，以侦探为中心的 3x3 格子变成"过去"（案发当晚）。 |
| 烟雾停留 | 烟停在吐出的位置，在烟里走动、互动都不会散。走出烟雾，或者 8 个行动后浓度耗尽，就回到现在。 |
| 改动保留 | 在过去做的改动会保留到现在。 |
| 跨时代携带 | 物品可以随意在过去和现在之间携带。 |
| 时间点 | 每个案件固定一个"案发时刻"。 |
| 引擎 | Godot 4.7，导出网页版和 Mac 版。关卡是 `levels/` 里的场景，可以在 Godot 编辑器里直接编辑（见 README）。 |

### 一条总原则：改变世界只能在过去

"现在"只能看、问、拿；推、点火、放东西、送烟，全都只能在烟雾里做。所以每个谜题都会落到同一个问题上：**这一夜会怎样把我在过去做的事，变成现在的样子？**

现在 = 过去 + 这一夜的流逝。引擎里只有一套推导规则，三个案件都用它：

| 推导规则 | 内容 | 首次出现 |
|---|---|---|
| 留下 | 过去推过的家具，现在还在新位置 | 案件一 |
| 后来的建造 | 案发后才砌的墙、钉的门、上的锁。如果过去那一格被东西占着，或者负责的人没走到，就不会出现 | 案件一（砖墙）→ 二（木板）→ 三（门锁） |
| 燃烧 | 用烟斗点燃的蜡烛会烧一整夜，四邻的可燃物到现在会烧光 | 案件二 |
| 融化 | 冰块到现在会化掉，除非放在冷的格子上 | 案件二 |
| 人的去向 | 过去的人在这一刻之后还会走动，他们现在在哪、看见了谁，都由这段路决定 | 案件三 |

## 谜题设计原则

针对"钥匙门太套路"的反馈，定了三条规矩：

1. **没有"捡钥匙开对应的门"这种一步链。** 每个关键证据至少要串起两种机制，例如穿墙进屋，再在屋里推家具、开后门。
2. **锁是"为什么会锁上"的结果，而不是一个物件。** 砖墙是有人后来砌的，木板是后来钉的，门锁是列车员走过去才锁上的。解法是让"后来的那件事"没能发生，而不是找钥匙。
3. **同一个目标至少有两条路，代价不同。** 穿墙每次都要花烟；让墙从来没砌成，一次就能永久打通。玩家用烟丝的多少来衡量这两条路。

## 三层机制，横跨三个案件

每个案件引入一层新规则，后面的案件复用并组合前面的。这样第三个案件里，玩家手上有三层工具，而不是只用第三层。

| 机制 | 案件一 · 反锁的书房 | 案件二 · 雪夜旅馆 | 案件三 · 末班列车 |
|---|---|---|---|
| **第一层：空间**（推动、留下、穿墙） | **引入**：推开书架露出暗格；推开衣橱打通后门；穿过后来砌的墙 | **变化**：把冰块推进门洞，让门钉不上（"占位"） | **复用**：门锁也遵守"后来的建造"规则 |
| **第二层：时间流逝**（燃烧、融化、对照） | — | **引入**：点燃蜡烛烧掉柴堆；冰块到早上化掉；冰锥架今昔对照 | **复用**：工具箱今昔对照找凶器 |
| **第三层：人的去向**（路线、引诱、目击） | （伏笔）给女仆烟丝，她去后院，证词就变了 | （伏笔）掌柜提到"厨子出去过一趟" | **引入**：烟雾里能看到人接下来的路；用烟丝把烟民引到别处，他就不会去锁门，还会撞见凶手 |
| **对质** | 引入 | 复用 | 由"目击"代替 |
| **烟丝** | 开窗、送人、换指纹的烟灰 | 新用途：点火 | 新用途：当诱饵 |

## 烟丝资源系统

核心想法：**烟丝本身也是存在于两个时代的物品**，所以它也遵守"改动保留"规则。游戏里没有评价分数，压力完全来自关卡：烟丝不够把每条路都走一遍，你得选。

| 环节 | 案件一 | 案件二 | 案件三 |
|---|---|---|---|
| 获取（现在） | 书房烟灰缸 +1；密室烟丝罐 +1；花园烟丝罐 +1 | 大堂烟灰缸 +1；冰窖旁的烟丝罐 +1 | 死者行李里 +1；C 车厢外的烟丝罐 +1 |
| 获取（过去） | 书房烟丝罐 +2（拿了，现在那只罐子和上面的指纹就没了）；走廊里的烟袋 +1（和送女仆烟在同一口烟里） | 厨房烟丝盒 +2（和对质在同一口烟里） | 餐车柜台上没拆的一包 +2（到早上已经被分光） |
| 消耗 | 开窗；送给过去的女仆，换来新证词 | 开窗；**点火**（把烟斗里的火种倒在蜡烛上） | 开窗；**诱饵**（放在过去的烟灰缸里，引来最近的一个烟民） |
| 副产品 | 烟灰拓指纹 | 烟灰 | 烟灰 |
| 开局 | 1 撮 | 1 撮 | 2 撮 |

### 烟丝锚点：把补给变成路线图

所有烟丝来源都是**锚点**，从开局起就画在地图上，玩家可以先看清补给在哪，再规划路线。

所有烟丝来源共用同一个模型（烟丝罐），不加角标。

| 锚点状态 | 画法 |
|---|---|
| 在当前时代 | 实体烟丝罐，外圈有一道闪动的金边，走过去碰一下就能拿 |
| 在另一个时代 | 同一个模型的半透明虚影，要换个时代才拿得到 |
| 同一格两个时代都有东西 | 先画现在的；现在的拿完或消失后，才露出过去的虚影 |

案件一书房里那只空烟丝罐（带指纹）也用同一个模型，但没有金边：它是罐子，但已经空了。过去的满罐子就藏在它后面，要吐烟才看得到。

顶栏汇总一行："烟丝锚点：现在 N 处 +x · 过去 M 处 +y"。

锚点让规划变成一道题：**过去的锚点只能在烟雾里拿，所以最划算的是把它和别的事放进同一口烟。** 例如案件一的烟袋就在女仆旁边，一口烟里既送烟又补烟；案件二的烟丝盒就在厨师旁边，一口烟里既对质又补烟。

### 地图

每个案件的核心区域（18x10）外面套了一圈走廊和附属房间，整张图 26x14。

- 外圈有花园、马厩、餐车等区域，放着额外的锚点和障碍物，绕路要花步数。
- 外圈的门只通向没有机关的房间。密室、冰窖、账房、C 车厢仍然只能靠机制进去，外圈不会变成捷径，也不会绕开 NPC 的路线。

## 三个案件（原型都已实现，均有自动通关测试）

### 案件一 · 反锁的书房（空间）

现在是次日 9:00，烟雾里是案发当晚 22:50。

| 证据 | 因果链 |
|---|---|
| 在场（三选一） | **对质**：让过去的管家出现在烟雾里，再碰窗口外现在的管家。**指纹**：用烟灰拓现在那只烟丝罐，但如果你拿过过去的罐子，这条路就没了。**女仆证词**：送过去的女仆一撮烟丝，她就会去后院抽烟，撞见管家。 |
| 凶器 | 书架在现在被钉死了。在过去把它推开（茶车挡着一侧，要想好从哪推、烟往哪吐），现在原来的位置就露出暗格。 |
| 动机 | 从砖墙那里穿进密室（砖墙是案发后砌的）。在密室里再吐一口烟，同一口烟里完成两件事：把堵住后门的衣橱推开，并从过去还开着的保险箱里拿遗嘱。衣橱推开后，后门在现在就通了，不用再花烟出去。如果不推衣橱，烟丝会刚好不够，困在密室里。 |

### 案件二 · 雪夜旅馆（时间流逝）

现在是次日 7:00，烟雾里是 21:00。老板死在账房，身边只有一滩水。

| 证据 | 因果链 |
|---|---|
| 在场 | 对质厨师，九点整的他正在厨房磨冰锥。同一口烟里能拿到厨房的烟丝盒（+2）。 |
| 凶器 | 冰窖门在现在被钉死了。在过去把厨房里的冰块推进门洞，木板就钉不上；冰块到早上化掉，门就开了。进冰窖后，先看现在的冰锥架（六根），再吐烟看过去的（七根），对照出少了一根。 |
| 动机 | 账房门口堆满柴火。在过去用烟斗点燃蜡烛（花 1 撮），推到柴堆旁边；蜡烛烧一整夜，柴堆到早上就烧光了，现在可以走进账房看账本。 |

### 案件三 · 末班列车（人的去向）

现在是次日 6:00，烟雾里是 23:10。烟雾里能看到过去的人接下来要走的路线（金色虚线）。

| 证据 | 因果链 |
|---|---|
| 在场（二选一） | 默认情况下，没有人看见行李员半夜穿过车厢。在 B 车厢过道的烟灰缸放一撮烟丝，列车员（烟民）就会坐那儿抽到半夜，正好撞见行李员；或者在 A 车厢的烟灰缸放，引来老先生。每个烟灰缸只引来离它最近的一个人。 |
| 动机 | C 车厢的门是列车员 23:20 锁的。如果他被烟丝引走，就永远走不到门口，门到现在也没锁，可以直接进去看电报。（也可以每次吐烟穿过去，但要花两次烟。） |
| 凶器 | 工具箱今昔对照，少了一把扳手。和 B 车厢的烟灰缸在同一口烟里。 |

最省的解法只用 2 撮：一口烟里对照工具箱，再在 B 车厢的烟灰缸里放一撮烟丝。这一撮同时解决了目击证人和门锁两件事。

## 美术与音效方向

美术方向是**黑色电影俯视图**，全部在 `scripts/art.gd` 里程序化绘制，不用贴图。

| 部分 | 做法 |
|---|---|
| 调色 | 物件都按"真实颜色"定义，再按时代统一调色：现在是冷蓝夜色，过去是暖褐老照片色调。所以每件东西只画一次，两个时代自动区分 |
| 光影 | 一层光影着色器：侦探周围有台灯光圈，远处变暗；整屏暗角和胶片颗粒；烟雾窗口里加暖色颗粒和划痕 |
| 地面 | 每个案件不同：书房是拼花地板、外圈是花园；旅馆是木地板、外圈是雪地；列车是红地毯、外圈是站台 |
| 墙 | 墙顶加立面，墙下有投影，墙线上的缺口画门槛 |
| 人物 | 侦探是风衣、礼帽、烟斗，有烟时烟斗冒火星和烟；其他角色各有造型（管家白领、女仆围裙、厨师高帽、列车员制服帽等）。靠近两格内才显示名牌 |
| 物件 | 书桌、书架、衣橱、保险箱、冰锥架（现在 6 根，过去 7 根）、工具箱（过去有扳手，现在只剩印子）等，都画成俯视图形 |
| 路线 | 过去的人接下来要走的路画成一串金色脚印，终点打叉 |
| 界面 | 顶栏有烟丝罐图标和证据档案标签；消息是一张便条纸；结案是盖章的档案卡；标题画面是雨夜路灯下的侦探剪影 |

音效方向：现在是冷色调的环境音；烟雾里叠一层老唱片底噪和爵士乐，吐烟时音乐交叉淡入。
