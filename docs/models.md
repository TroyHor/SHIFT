# 用 Dify 工作流做模型

游戏里的物件和人物原来全是在 `scripts/board3d.gd` 里用方块、圆柱拼出来的。现在可以用本机 Dify 的「Godot 素材生成器」工作流（Gemini 整理需求 → Tripo 出概念图、四视图、建模、上贴图）做成真模型，一个一个换进来。

## 怎么换进游戏

- 模型放在 `assets/generated/<名字>/<名字>.tscn`。名字就是物件的画法名（下表第一列）。
- 有模型就用模型，没有就还是程序拼的。所以可以一次换一个，也可以随时删掉退回去。
- 模型自动摆到程序拼的那一份的位置和大小：底部贴地、居中、最长的一边和程序拼的一样长、不出这一格（最多高出一倍）。关卡不用改。
- 模型的贴图只留颜色，光照换成游戏自己的着色：现在是清晨的白光，烟里是夜里的月光和灯光，和其它物件一样。
- 会变的部分始终用程序画：书桌上的台灯（夜里亮）、保险箱的转盘和打开的门、冰锥架上的冰锥根数、蜡烛的火苗、余烬、工具箱里的工具、烟灰缸里的烟丝、暗格里的东西、侦探的烟斗火星。
- 朝向不对时在 `Board3D.MODEL_YAW` 里加一项转过来。

## 流程

1. 在 Mac 的 Claude Code 里用 dify-godot-assets 的 `start_asset`（类型 `3D 静态模型`），brief 用下面的「共用风格」加上表里那一行。
2. `deliver_to_godot` 交付到一个单独的文件夹（不要直接交付进这个仓库，原始模型一个 10–17 MB）。
3. `tools/models/add.sh <交付文件夹> <名字>`：去掉法线和金属粗糙度贴图、颜色贴图缩到 512、网格简化到 6000 三角面以内，一个模型约 0.2 MB；写好 tscn 和来源记录。
4. `godot --headless --path . --script res://tools/model_tints.gd`：算每个模型的校色系数，写进 `scripts/model_tints.gd`。模型的平均色会被拉回程序拼的那一份（也就是美术文档的配色），整套模型色调统一；贴图另外取模糊一层，细碎的写实纹理变成大块上漆的颜色。
5. `godot --path . --rendering-driver opengl3 --script res://tools/model_sheet.gd -- 对照.png` 出对照图：程序拼的、模型白天、模型夜里三行并排。

## 共用风格（每个 brief 都加在前面）

> 1940 年代美国犯罪现场微缩模型（Nutshell Studies 那种剖开的娃娃屋）里的一件手工木头模型。哑光上漆，边角微微圆润，形状简化、块面清楚，从斜上方俯视、只有几十像素时也认得出。单个物体，居中，正面视角，纯白背景，不要底座、不要文字、不要地面。

人物另加（人物例外：要底座，所以把共用风格里的「不要底座」删掉）：

> 上漆的木头小人（桌游棋子那样），锥形身体、圆头、简单的手臂，站在一块黑色圆底座上。靠帽子和一两件配饰认出身份。
